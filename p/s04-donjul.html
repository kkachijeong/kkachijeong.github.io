돈줄 · 가계 자금 흐름 웹 서비스

가계의 자금 흐름을 그리고, 가계부 거래를 분류해 흐름 구조의 문제를 짚어 주는 웹 서비스

기간
2025.08 ~ 2026.07
역할
1판 단독, 2판 2인 중 백엔드(스키마·API·LLM)
  • React
  • React Flow
  • FastAPI
  • Supabase(Postgres·Auth)
  • Anthropic Python SDK
  • Docker
  • GitHub Actions

무엇을

두 판이 있습니다. 1판(2025.08 ~ 10)은 수입원·계좌·지출처를 노드로, 자금 흐름을 엣지로 그려 가용자금을 계산하는 웹 앱으로, Supabase Auth와 RLS로 사용자별 데이터를 나누고 Docker·nginx로 donjul.com에 배포했습니다. 2판(2026.05 ~ 07)은 뱅크샐러드 가계부 엑셀을 올리면 LLM이 거래를 분류하고 자금 흐름 구조를 시각화해 개선안을 제안하는 서비스로, 1판은 참고만 하고 새로 만들었습니다.

왜

맞벌이 부부처럼 돈의 흐름이 복잡한 가계가 자기 재정 흐름을 한눈에 보고, 어떻게 바꾸면 좋을지 추천받게 하려고 만들었습니다.

어떻게

  • 숫자 집계·통계는 결정적 코드가 계산하고, LLM은 그 결과의 해석과 서술만 담당
  • 가족 간 이체 감지에 LLM 미사용. SQL로 시간 차·금액 일치 후보를 뽑은 뒤 은행 마스킹(*)을 와일드카드로 본 별칭 매칭과 호칭 사전 매칭으로 방향 판정
  • 2판 구조로 React + FastAPI 분리 채택. LLM 스트리밍·도구 호출, 2인 협업, Python 데이터 생태계를 Next.js 풀스택의 단순성과 비교해 결정

결과

1판은 혼자 커밋 115건으로 만들었습니다. 2판은 커밋 333건, API Python 약 1.6만 줄 규모이고, 작업은 GitHub Issue·Project로 나눠 관리했습니다. 2026.07에 개발을 멈췄고 지금은 운영하지 않습니다.
