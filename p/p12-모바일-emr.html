모바일 AWS EMR 인프라

PC판 온프레미스와 다른 AWS EMR 위에 모바일 게임로그 백엔드 전개와 백업 자동화

기간
2023 ~ 현재
역할
2~4인 중 선행 검증, 조회 SDK .NET 6 이식, CDK 전개, HDFS → S3 백업 담당 (서비스 도커 배포는 일부)
  • AWS EMR
  • EC2
  • S3
  • MMSK
  • Lambda
  • EEventBridge
  • SSSM
  • AWS CDK(Java)
  • .NET 6

무엇을

모바일 로스트아크의 게임로그 백엔드를 PC판 온프레미스(Cloudera)와 다른 AWS EMR과 EC2 위에 세운 일입니다. 그중 선행 검증, 조회 SDK 이식, CDK 전개 코드, HDFS → S3 백업을 맡았습니다.

왜

모바일판 데이터 백엔드는 PC판과 달리 AWS EMR 위에 두었습니다. PC에서 쓰던 조회 SDK와 운영 도구가 EMR에서 그대로 도는지부터 확인해야 했습니다.

어떻게

  • 선행 검증(2021~2022, 북미 서비스용 EMR): .NET Livy SDK의 EMR 호출 시 YARN 큐·메모리·Jars 경로 문제 정리, EMR Step 취소 후 살아남는 Spark 앱을 yarn kill 스크립트로 정리
  • 조회 SDK .NET 6 이식: .NET 6에서 깨지는 BinaryFormatter 직렬화를 JSON으로 교체, 모바일 운영툴과 PC의 로깅 차이를 delegate 기반 Logger로 연결
  • AWS CDK(Java)로 MSK·EC2 전개 코드 작성
  • HDFS → S3 백업: Lambda + EventBridge + SSM으로 EMR 마스터에서 distcp 원격 실행, 최근 N시간은 무조건 재백업하고 그 이전은 없는 파일만 복사

결과

  • 인프라팀으로 넘어가기 전까지 직접 짠 CDK 코드로 전개, 지금은 요구사항을 정리해 인프라팀에 전달
  • S3 백업을 QA에서 CBT 환경까지 확장
