LLM이 틀려도 실계좌가 망가지지 않는 주식 매매 시스템

기간
2026.04 ~ 현재
역할
단독
  • Python
  • SQLite
  • 한한국투자증권 Open API
  • Claude Code
  • Llaunchd
  • 텔레그램 봇

무엇을

국내·미국 주식을 실계좌로 매매하는 시스템입니다. 매매 판단은 LLM에 맡기되, 주문·한도·장부는 코드가 강제하고 증권사 잔고와 대사해서 LLM이 틀려도 계좌가 망가지지 않게 했습니다.

왜

개인적인 용도로 실제 쓰려고 만들었습니다. 판단을 LLM에 맡기는 만큼, 돈이 움직이는 경로는 LLM이 틀려도 버티도록 코드가 지키게 하는 것이 목표였습니다.

어떻게

  • 주문 원장 선기록 후 전송, 재전송 금지. 결과 미확인 주문은 미확정 처리 후 조회로 확정 (타임아웃 재시도로 인한 중복 체결 가능성 제거)
  • 주문·리스크 검사·대사를 별도 OS 사용자 프로세스로 분리, LLM 측 요청 재검증. 장부에 없는 체결 감지 시 신규 진입 중단
  • LLM이 꺼져 있으면 청산만 허용하고 신규 진입 차단. 총자산 고점 대비 -40% 하드킬, 값과 재가동은 사용자만 변경
  • 증권사·텔레그램 같은 외부 입출력과 시각을 주입 가능하게 분리, 가짜 증권사 서버로 테스트

결과

  • 2026.04 국내, 2026.06 미국 실계좌 체결 시작. 2026.10 현재 운영 중
  • 2026.10.08부터 주문 송신을 끈 섀도 운영, 2026.10.14 실주문을 분리한 프로세스 경유로 전환
  • 커밋 1,621건, 테스트 2,119개(2026.10.12 기준), 설계 스펙 28건
