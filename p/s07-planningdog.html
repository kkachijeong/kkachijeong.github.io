무엇을

정의서(정책·기획·설계 문서)를 사람이 직접 고치지 않고 AI와의 대화로만 바꾸게 하고, 바뀐 문장마다 결정 근거를 남기는 Claude Code 플러그인입니다. 2인 팀 사이드 프로젝트에서 정의서를 이 방식으로 관리했습니다.

왜

빠르게 개발하려고 담당 범위를 나누지 않고 함께 개발하다 보니, 한 사람이 고친 곳을 다른 사람이 다시 고치는 일이 잦았습니다. 고친 의도를 알 수 없어 다시 고쳐도 되는지 매번 따로 물어봐야 했습니다. 바뀐 문장마다 의도를 남겨, 묻지 않고도 판단할 수 있게 하는 것이 목표였습니다.

어떻게

  • 정의서를 고치기 전 관련 결정 검색을 강제. 기록에 없으면 "기록 없음"으로 답하게 해 AI가 근거를 지어내지 못하게 함
  • 정의서 문장에 결정 기록 링크를 달아, 백링크로 영향 범위를, 대체 관계 체인으로 지금 유효한 결정을 찾음
  • 코드 변경을 정책 문장과 대조해 어긋난 곳만 보고하는 대조 에이전트. 코드 읽기는 메인 대화와 분리
  • Claude Code 매니페스트를 정본으로 두고 Codex 매니페스트는 스크립트로 생성해 두 도구에서 사용

결과

플러그인은 혼자 커밋 14건으로 만들었고, 팀원도 같은 방식으로 정의서를 고쳤습니다.
