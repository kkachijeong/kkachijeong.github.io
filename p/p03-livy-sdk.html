Spark(Livy) 대량 조회 경로

Phoenix로는 안 되던 긴 기간·대량 게임로그 조회를 운영툴에서 Spark로 할 수 있게 한 조회 SDK의 2세대 경로

기간
2020 ~ 2022
역할
단독 (Orca SDK 설계·개발·운영 담당)
  • C#/.NET
  • AApache Livy
  • Spark DataFrame
  • Scala

무엇을

조회 SDK에 Spark(Livy) 경로를 추가해, 운영툴에서 긴 기간과 많은 데이터를 조회하고 내려받을 수 있게 했습니다. 2022년 LIVE에 적용했습니다.

왜

Phoenix로는 대용량 검색이 불가능했습니다. 기간이 길어지면 타임아웃이 났고, HBase는 행 키 설계 밖의 조건이면 전체 리전을 훑어야 했습니다. 그래서 긴 기간·대량 데이터를 위한 순수 조회·다운로드 기능을 Spark로 만들었습니다.

어떻게

  • .NET에서 Spark를 직접 붙일 수단이 없어 Livy REST로 세션 생성 → statement 제출 → 폴링 → 결과 수신 구현
  • 쿼리 생성을 spark.sql 문자열에서 DataFrame filter 체인 Scala 코드 생성으로 재작성 (문자열 방식은 성능 미달)
  • 요청마다 세션을 만들면 초기화에 수십 초가 들어 세션 유지, idle executor 회수와 세션 timeout은 설정으로 조절
  • 분 단위 조회라 비동기 인터페이스와 처리 상태 조회 추가, Livy 서버 재시작 뒤 남는 유령 세션은 상태 재확인 후 복구·재생성

결과

  • 2022년 LIVE 적용, 모바일 EMR의 Livy 서버 호출 환경 차이(YARN 큐·메모리, Jar 경로) 정리
  • 조회 SDK가 HBase/Phoenix, Spark(Livy) 두 경로를 갖춘 2세대 구조
이전조회 SDK 모바일 이전과 Phoenix 키 기반 페이징 전환다음게임로그 조회 경로 Iceberg/Trino 전환
