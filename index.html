실시간 이상탐지 엔진 Thunder Eye

2022 ~ 2024 · 2인 중 백엔드(스트리밍 엔진, 저장, API)와 운영툴 웹 통합 인증 담당

어뷰징과 버그 악용을 배치보다 먼저 잡는 게임로그 실시간 이상탐지

한 일

  • 실시간 탐지 파이프라인 구현
  • Spark 2.3 Structured Streaming 장시간 구동 시 메모리 누적 중단에 주기적 재시작 구현으로 대응, 재시작 지점 기록으로 재처리 시 집계 중복 방지
  • 5분 단위 결과 파일 무한 증가 문제를 시간·일·월 단위 병합과 오래된 데이터 평균 압축 보관 정책으로 해결
  • 운영툴 웹 통합 인증 구현: 웹을 새로 짜지 않고 Orca Eye에서 iframe/redirect로 연결, JWT 원클릭 로그인과 즉시 만료, LDAP 연동, X-Frame-Options·SameSite 쿠키·안티포저리 토큰 처리

결과

  • 비정상 로그인 급증, 이벤트 당첨자 수 급변 같은 게임상 문제를 5분 단위로 탐지
  • 새 감시 항목은 코드 배포 없이 메시지 등록으로 추가

실 공용 빌드·배포 파이프라인

2019 ~ 현재 · 단독

실(室)의 모든 팀이 빌드·배포 설정을 나에게 요청하지 않고 직접 할 수 있게 다시 세운 공용 파이프라인

한 일

  • 파일이 Git → 빌드 서버 → 배포 서버 → IDC망 배포 서버 → 대상 서버로 여러 번 옮겨지는 구조라, 설정 값을 뺀 최종 배포본과 빌드본을 해시로 비교하는 무결성 검증 추가
  • cherry-pick 형상관리에서 누락 커밋이 쌓여 릴리스 때 대량 병합 충돌이 나던 것을 브랜치 주기 백업·재생성 자동화로 차단, 이후 GitLab CI로 이전
  • Jenkins Job 안에 직접 쓰여 개발망·IDC망끼리 어긋나던 배포 스크립트를 Git으로 옮기고 배포 스크립트 전용 저장소 분리
  • 2026년 VPC 분리에 맞춰 AWS Docker 서비스 배포를 직접 SSH에서 S3 경유(대상 서버가 가져가는 방식)로 전환

결과

  • 북미·중국·러시아 등 국가·퍼블리셔 전용 빌드와 모바일 전용 빌드 서버까지 배포 매트릭스 확장
  • 신규 IDC Docker 배포에 대수 단위로 묶는 병렬 배포 잡 추가 (기존 순차 배포가 오래 걸려 대수 단위로 묶음, 8대 시험 배포 완료)

기술

  • Perforce

auto-stock · 주식 실매매 시스템

2026.04 ~ 현재 · 단독

LLM이 틀려도 실계좌가 망가지지 않는 주식 매매 시스템

한 일

  • 주문 원장 선기록 후 전송, 재전송 금지. 결과 미확인 주문은 미확정 처리 후 조회로 확정 (타임아웃 재시도로 인한 중복 체결 가능성 제거)
  • 주문·리스크 검사·대사를 별도 OS 사용자 프로세스로 분리, LLM 측 요청 재검증. 장부에 없는 체결 감지 시 신규 진입 중단
  • LLM이 꺼져 있으면 청산만 허용하고 신규 진입 차단. 총자산 고점 대비 -40% 하드킬, 값과 재가동은 사용자만 변경
  • 증권사·텔레그램 같은 외부 입출력과 시각을 주입 가능하게 분리, 가짜 증권사 서버로 테스트

결과

  • 2026.04 국내, 2026.06 미국 실계좌 체결 시작. 2026.10 현재 운영 중
  • 2026.10.08부터 주문 송신을 끈 섀도 운영, 2026.10.14 실주문을 분리한 프로세스 경유로 전환

기술

  • Python
  • SQLite
  • 한한국투자증권 Open API
  • Claude Code

  • 텔레그램 봇
